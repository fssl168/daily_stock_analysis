# 纸面交易系统 → 实盘切换 项目实施计划清单

> 状态：评审稿 / 待确认
> 更新：2026-08-13
> 作者：项目经理（基于全流程 E2E 亲历测试 + 代码核实）
> 范围约束（本项目决策）：**本阶段不接入实盘交易**。所有纸面交易（paper trading）功能测试跑通后，再进入实盘切换阶段。本文档即"纸面完备 → 实盘就绪"路线图。

---

## 0. 定位与本阶段目标

系统定位：**股票 + 固定收益 量化交易执行系统**（覆盖 A 股 / 港股 / 美股）。

本阶段唯一目标：把**纸面交易全链路打磨到可稳定运行、可验证、可复盘**，为实盘切换建立可靠地基。不引入任何真实券商资金/交易，不开启实盘 broker。

**判定标准（纸面完备的退出条件）：**
- 全部纸面功能模块有测试覆盖，`ci_gate.sh` 通过
- 纸面交易全流程（信号→风控→成交→持仓→净值→复盘）在无人工干预下可运行 N 个交易日
- 行情→定价→成交价 闭环无失真（消除"参考价成交 vs 实时估值"漂移）
- 关键 Agent 能力（PM 决策/复盘/作战计划）有非 fallback 的真实运行验证
- 示例数据 / 演示环境可一键复现

## 2. 差距分析（与"可执行系统"定位的差距）

### 2.1 差距一：定价闭环缺失（执行系统地基）— 高优先级

现状：市价单成交价 = `limit_price`（前端传入的参考价），与实时行情脱节。
实测影响：演示数据中 600519 以 1680 成交，持仓按实时 1343 估值 → 浮亏 -24% 失真。

**目标**：`实时行情 → 滑点模型 → 成交价` 闭环，行情走 `SharedQuoteCache` 缓存，下单不再打慢数据源。

### 2.2 差距二：固定收益模块缺失（定位缺口）— 需决策

现状：全仓库无债券数据源、收益率曲线、久期/凸性、信用利差、回购模块。代码事实 = "股票 + 现金"。

**决策点**：固收做，则立项最小闭环；不做，则收敛定位为"股票执行系统"并同步文档，避免愿景漂移。

### 2.3 差距三：实盘切换缺少前置条件（阶段约束）

现状：执行层 100% 走 `paper_broker`；`eastmoney_broker` adapter 存在但被配置关闭；`BrokerRouter` 已具备按账户路由能力但未在真实券商验证。

**本阶段明确不做**：不开真实券商、不接实盘资金、不启用 eastmoney broker 的实盘路径。但**保留** broker 抽象层（`BaseBroker`/`BrokerRouter`）作为切换点，并在计划中列出"切换前置清单"。

### 2.4 差距四：Agent 能力是"纸面的纸面"（能力验证缺口）

现状：PM 决策 / 复盘 / 作战计划在无 LLM 密钥下全走 fallback。能力代码存在，但未验证真实推理质量。

## 3. 实施计划（分阶段，含验收标准）

### P0 — 还债与止血（第 1 周，必做）

#### T-01 补回归测试 + 合入本次修复
- **内容**：为 3 处修复补 pytest：
  - WS 握手：未登录 → 拒绝；已登录 → 200 握手并收到消息/超时正常
  - `backtest-scenario`：含 net-value 数据的账户返回 200，date 为 ISO str
  - `battle-plans`：seed 数据可序列化
- **验收**：`python -m pytest -m "not network"` 通过；`./scripts/ci_gate.sh` 通过
- **交付**：整理为 1 个 PR（含 CHANGELOG `[Unreleased]` 扁平条目）

#### T-02 建立下单定价闭环
- **内容**：
  1. 市价单成交价改为 `SharedQuoteCache` 实时行情 + 滑点模型；行情缺失时明确降级策略并记录日志
  2. `limit_price` 降级为"兜底参考价"而非默认成交价
  3. 持仓 `last_price` 与成交价同源，消除浮亏失真
- **验收**：E2E 脚本断言：市价单成交价≈实时行情（偏差≤滑点）；演示账户浮亏率与实际行情一致
- **交付**：`tests/` 新增定价闭环测试

#### T-03 演示环境固化
- **内容**：把 `/tmp` 的 `gen_data.py` / `seed_backtest_report.py` / `seed_agent_tables.py` 整理进 `scripts/`，参数化（账户名/资金/股票池/交易日数）
- **验收**：`python scripts/seed_demo_data.py --account demo --capital 1000000` 一条命令复现全部示例数据
- **交付**：`scripts/` 新增脚本 + `docs/` 使用说明

### P1 — 纸面完备度（第 2~3 周）

#### T-04 固收定位决策
- **内容**：评审 2.2，拍板"做 / 不做 / 延后"
- **若做（最小闭环）**：
  - 国债收益率曲线数据源（akshare/东方财富 中债曲线）
  - 组合久期 / 凸性 风控指标（RMS 扩展）
  - 股债再平衡信号（Agent 信号源之一）
- **若不做**：更新 `README.md` / `IDEA.md` 定位表述为"股票执行系统"，记录决策理由
- **验收**：有明确的决策记录（ADR 或文档）

#### T-05 Agent 真实能力验证
- **内容**：配一次真实 LLM 密钥，跑通非 fallback 路径：
  - `POST /pm-decisions/trigger` 产生真实决策
  - `POST /reflections/daily` 产生真实复盘
  - `POST /battle-plans/generate` 产生真实作战计划
- **验收**：3 个端点 `used_fallback=false`，产物质量人工评审记录
- **交付**：验证报告 + 潜在 bug 清单

#### T-06 纸面交易稳定性演练
- **内容**：`MarketListener` 连续运行 ≥5 个交易日（可用回放/模拟行情），验证：
  - 日结算 / 日净值曲线 / 每日复盘自动触发
  - 极端行情事件、熔断、风控告警推送
- **验收**：5 日无崩溃、无未捕获异常、净值曲线连续

### P2 — 实盘就绪（第 4 周起，仅在纸面完备后启动）

#### T-07 实盘切换前置清单（不执行实盘，仅准备）
- **内容**：产出并评审《实盘切换检查单》：
  - 风控参数校验（限额/熔断/滑点/断线处理）
  - 券商 sandbox 接入验证（eastmoney 或长桥 openapi，`BrokerRouter` 真实路由）
  - 订单幂等 / 回报回写 / 对账
  - 权限与告警（实盘操作确认流程）
  - 回滚方案（一键切回 paper）
- **验收**：检查单评审通过，所有"纸面→实盘"差异点有明确方案

> ⚠️ 注意：T-07 只做**准备与验证**，**不开启真实交易**。切换动作需另行立项、另经确认。
