# 功能精简评审决策 ADR（P2-1）

> 日期：2026-08-14
> 状态：已评审待执行
> 定位：对功能矩阵做「保留 / 冻结 / 裁剪」决策，控制膨胀，聚焦「后端组织能力 + Agent 自我进化」核心愿景

---

## 1. 背景

项目自 3 月至今 590+ commit，功能矩阵持续膨胀（多市场分析、Bot、问股、图片导入、L1-L4 可观测性、干预模式、50+ API 端点、15 个实时组件）。规划文档自评「能力密度高，可靠密度不足」。本 ADR 依据核心愿景——**后端组织能力 + Agent 调度/自我学习/自我反思**——对功能面逐项打分决策。

## 2. 评审方法

每个功能面按三维打分（1-5）：

| 维度 | 含义 |
|---|---|
| **愿景契合** | 是否增强「后端组织 / Agent 自我进化」（核心愿景） |
| **用户价值** | 实际使用频率与不可替代性 |
| **维护成本** | 代码量、依赖复杂度、与核心链路的耦合风险 |

决策规则：
- **保留**：愿景契合 ≥ 4，或用户价值 ≥ 4 且维护成本 ≤ 3
- **冻结**：愿景契合 2-3，或维护成本 ≥ 4 且近期无迭代需求（不删，停止投入）
- **裁剪**：愿景契合 ≤ 1 且维护成本 ≥ 4，或明确与愿景冲突

### 3.4 待决策（冻结/裁剪候选）

| 功能面 | 愿景 | 价值 | 成本 | 决策 | 理由 |
|---|---|---|---|---|---|
| **桌面端（Electron）** | 2 | 3 | 5 | ❄️ **冻结** | 与 Web 功能重叠，构建链路复杂（Electron+自动更新+签名），维护成本最高；用户实际以 Web 为主 |
| **多语言（zh/en/ko/jp 全量文案）** | 1 | 2 | 4 | ❄️ **冻结** | 核心用户中文；日/韩文案（AlertRuleForm JP/KR 等）已在服务边界移除，继续维护全量翻译不划算。保留 zh/en 双语文案（已有） |
| **图片导入/OCR 分析** | 1 | 2 | 4 | ✂️ **裁剪候选** | 与「股票分析」主用途弱相关，依赖 OCR 链路与图像处理依赖；若未来无明确需求应移除 |
| **Bot 全平台接入**（QQ/Telegram 等非核心渠道） | 2 | 2 | 4 | ❄️ **冻结** | 保留 Lark/钉钉/微信（通知主渠道），QQ/Telegram 等扩展渠道冻结 |
| **股票自动补全（多市场）** | 2 | 3 | 2 | ✅ 保留 | 低成本高 UX 价值（保留现有实现，不再扩展） |
| **复权/基本面扩展（yfinance fundamental）** | 3 | 3 | 3 | ✅ 保留 | 分析质量输入（现有测试待修，投入有限） |

## 5. 影响面与实施建议

1. **冻结桌面端**：停止新功能投入；`apps/dsa-desktop/` 保留现状，Release 工作流（`build-desktop*`）不再排期新发布；文档标注「冻结」
2. **冻结多语言**：`i18n/uiText.ts` 保留 zh/en 完整；ko/jp 相关文案不再新增（现有保留）
3. **裁剪图片导入**：评估 `image_stock_extractor.py` 使用频率；若 30 天内无使用记录，标记废弃并在下个大版本移除（`docs/CHANGELOG.md` 标注）
4. **README/IDEA 定位更新**：定位从「功能矩阵」收敛为「股票分析 + 可执行交易系统 + Agent 自我进化」，删除/弱化非核心功能宣传
5. **执行节奏**：冻结为即时生效（停止投入）；裁剪需用户确认后单独 PR
